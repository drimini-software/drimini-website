# Security policy

The website accepts project enquiries and stores accepted submissions in a
private Cloudflare D1 database. Please report suspected vulnerabilities
privately instead of opening a public issue.

Email `contact@drimini.com` with:

- a concise description of the issue and its likely impact;
- the affected page, endpoint, or component;
- safe reproduction steps or a minimal proof of concept; and
- a suggested mitigation, if known.

Do not include real credentials, private source code, personal data, customer
information, or another party's confidential material. Do not disrupt the
production contact service or submit deceptive enquiries while testing.

No bug-bounty program, acknowledgement deadline, or remediation timeline is
currently promised.
